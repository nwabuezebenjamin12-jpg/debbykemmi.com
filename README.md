# debbykemmi.com

Professional business website for Debby Kemmi Business Solutions.

## About

This website serves as the online presence for Debby Kemmi, providing information about business services and solutions offered.

## Features

- Modern, responsive design
- Service showcase
- Contact form
- Social media integration (X/Twitter)
- Professional business presentation

## Running Locally

To view the website locally, open `index.html` in your web browser or run a simple HTTP server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

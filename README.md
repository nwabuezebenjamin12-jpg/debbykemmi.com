# debbykemmi.com

Personal website for Debby Kemmi.

## 🌐 Live Website

The website is deployed using GitHub Pages and is accessible at:
- https://nwabuezebenjamin12-jpg.github.io/debbykemmi.com/

## 🚀 Deployment

This website is automatically deployed to GitHub Pages using GitHub Actions whenever changes are pushed to the main branch or the copilot/deploy-website-online branch.

## 📁 Project Structure

- `index.html` - Main HTML file
- `styles.css` - CSS styling
- `.github/workflows/deploy.yml` - GitHub Actions workflow for deployment

## 🛠️ Local Development

To view the website locally, simply open `index.html` in your web browser.

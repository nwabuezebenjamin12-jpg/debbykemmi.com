The website is deployed using GitHub Pages and is accessible at:
- https://nwabuezebenjamin12-jpg.github.io/debbykemmi.com/

## 🚀 Deployment

This website is set up to be deployed to GitHub Pages using GitHub Actions.

**To enable deployment:**
1. Go to repository Settings → Pages
2. Under "Build and deployment", set Source to "GitHub Actions"
3. The workflow will automatically deploy on push to main or copilot/deploy-website-online branch

For detailed deployment instructions, see [DEPLOYMENT.md](DEPLOYMENT.md)

## 📁 Project Structure

- `index.html` - Main HTML file
- `styles.css` - CSS styling
- `.github/workflows/deploy.yml` - GitHub Actions workflow for deployment

## 🛠️ Local Development

To view the website locally, simply open `index.html` in your web browser.
